# 智能垃圾邮件过滤 — 启动说明

## 1. 数据库迁移

在 MySQL `mail_system` 库执行：

`mail-system-backend/src/main/resources/db/migration_spam_auto_filter.sql`

## 2. 启动顺序

```powershell
# 1. Python 检测服务（email-spam 目录）
cd email-spam
python web_app.py --port 8000

# 2. Java 后端（IDEA 或 mvn）
# mail-system-backend，端口 8080

# 3. Vue 前端
cd vue-mail-front
npm run dev
```

## 3. 使用方式

1. 登录 L邮箱
2. 打开 **收件箱**，打开工具栏 **「智能过滤」** 开关
3. 另一账号发送带促销/中奖类内容的邮件
4. 收件人若判定为垃圾邮件：不进收件箱，出现在 **垃圾邮件**，右下角 Toast 显示原因

## 4. 配置

`mail-system-backend/src/main/resources/application.yml`：

```yaml
spam-detector:
  enabled: true
  base-url: http://127.0.0.1:8000
  username: admin
  password: admin123
  spam-threshold: 0.5
```

Python 默认管理员：`admin` / `admin123`（首次启动 web_app.py 自动创建）
