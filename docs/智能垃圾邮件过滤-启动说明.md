# 智能垃圾邮件过滤 - 启动说明

## 1. 数据库迁移

在 MySQL `mail_system` 库执行：

`mail-system-backend/src/main/resources/db/migration_spam_auto_filter.sql`

## 2. 启动顺序

```powershell
# 1. Java 后端
# mail-system-backend，端口 8080

# 2. Vue 前端
cd vue-mail-front
npm run dev
```

## 3. 使用方式

1. 登录 L-email 系统
2. 打开 **收件箱**，开启工具栏里的 **垃圾过滤** 开关
3. 另一账号发送一封带促销/中奖/诱导内容的邮件
4. 若判定为垃圾邮件：
   - 不进入普通收件箱
   - 自动出现在 **垃圾邮件** 列表
   - 页面显示垃圾原因

## 4. 配置

`mail-system-backend/src/main/resources/application.yml`

```yaml
spam-detector:
  enabled: true
  model-path: classpath:spam_model.json
  spam-threshold: 0.5
  top-reason-count: 5
```

## 5. 训练与部署说明

- 模型训练目录：`email-spam`
- 运行时模型文件：`mail-system-backend/src/main/resources/spam_model.json`
- 垃圾邮件识别已改为后端内置插件，运行时不再需要独立 Python 服务
