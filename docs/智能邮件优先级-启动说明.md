# 智能邮件优先级

## 功能说明

在收件箱工具栏与「智能垃圾邮件过滤」并排提供 **智能优先级** 开关。开启后：

1. 新邮件进入收件箱且未被标为垃圾邮件时，后端调用 **VVEAI 大模型**（与 AI 助手相同配置）评估 `HIGH` / `MEDIUM` / `LOW`。
2. 将 `priority_level`、`priority_score`、`priority_reason` 写入 `mail_user_box`。
3. 收件箱列表按 `priority_score DESC, updated_at DESC` 排序，高优先级邮件排在前面。

## 前置条件

1. 在系统 **AI 设置** 中完成第三方模型接入配置，并 **启用** AI 助手。
2. 执行数据库迁移脚本：

```sql
-- mail-system-backend/src/main/resources/db/migration_priority_auto_filter.sql
```

## API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/mail/priority/auto-filter/status` | 返回 `{ enabled, aiConfigured }` |
| POST | `/mail/priority/auto-filter/enable` | 开启（需已配置 AI） |
| POST | `/mail/priority/auto-filter/disable` | 关闭 |

## 与垃圾邮件过滤的关系

- 先执行垃圾邮件检测；若已移入垃圾邮件，**不再**做优先级评估。
- 两者开关独立，可只开其一或同时开启。

## 启动

仅需 **Java 后端 + Vue 前端**，无需额外 Python 服务。

```bash
# 后端
cd mail-system-backend && mvn spring-boot:run

# 前端
cd vue-mail-front && npm run dev
```
